# 参考图耳机雕塑模型

`sculptural_headset.blend` 是可编辑的 Blender 4.3 文件，包含耳机主体、叶片头冠、鸟形羽翼装饰、编织藤蔓、悬垂线缆，以及用于预览的相机和灯光。

- `headset_preview.png`：白色背景的三分之四视角渲染。
- `sculptural_headset.glb`：仅含模型的通用三维交换文件。
- `create_model.py`：生成模型的完整 Python 脚本，无需外部素材或 Python 依赖。

模型按功能分为七个集合。羽翼和叶片保留为独立网格，藤蔓和线缆保留为可编辑的贝塞尔曲线；在曲线的编辑模式下调整控制点，在曲线数据属性中调整管径。GLB 文件中的曲线已转为网格。

打开 `.blend` 文件后，可按小键盘 `0` 切换到预览相机。隐藏 `07 Studio` 集合可单独查看模型；选中要编辑的对象并按小键盘小数点键，可将视图聚焦到该对象。场景使用灰色哑光材质和 Cycles 渲染，无需贴图。

重新生成：在包含 `create_model.py` 的文件夹中打开终端，运行：

```bash
blender --background --python create_model.py
```

这是依据单张参考图制作的外观模型。背面和隐藏结构进行了补全；尺寸未按实物标定，未制作电子结构、装配公差或用于打印的一体化实体。
